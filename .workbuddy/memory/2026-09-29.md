## 第三轮：黑洞体基础形状重做（本轮最严重）

用户原话："黑洞体看着像是三个五边形叠在一起，甚至都不是立体" + "塌缩和闪光都太快" + ">80 全部被吸入，不存在环流"。

### 实测定位 5 个叠加 bug（`src/gfx/l5Core.js`，注释前缀 `v-内容4-形`）
- **F（主因）**：sync 面板写入的正常分支里 `m.rotation.set(0,0,0)` **每帧把构造时摆好的面朝向抹成同一姿态** → 12 块板互相平行、位置又都挤在 0.085 处 → 就是"几个五边形叠在一起"。修法：每帧 `quaternion.copy(_bhFaceQuat[f])`，自旋用 `rotateZ`（绕局部 Z = 面法线）叠加，绝不用 Euler 覆盖。
- **A 尺寸**：`bhPanelGeo(BH_SHELL_R,…)` 把十二面体**外接半径**当**面上五边形**外接半径（差 1.647×）。
- **B 位置**：`position = n × bhLift`（上限 0.085），应在内切半径 0.20 处。
- **C 朝向**：`setFromUnitVectors(+Z, n)` 绕法线滚转随机 → 解真实面顶点 + `makeBasis(X=面心→顶点0, Y=Z×X, Z=n)`。
- **D 材质**：`transparent + depthWrite:false` 互相看穿 → `FrontSide + depthWrite:true + NormalBlending`，片元改非预乘 `vec4(col, alpha)`。
- 附带：内表面三角扇缺中心点（角顶点当扇心 → 退化面）；`BH_SHELL_T` 0.028→0.032。

### 规格改动

- 新增 `BH_PANEL_GAP = 0.10`；`bhPanelDist(r) = max(BH_SHELL_IN, r + BH_PANEL_GAP)` → 闭合 0.20，0.2–0.8 抬到 0.32，缝恒 0.1u，**大小不变**

## 第 6 轮（用户定标 + 调研后重设计）：透镜重做 / 回落三段 / 粒子错峰

### 调研结论（用户要求先调研；来源：Gargantua 渲染器 / EHT M87* / 测地线 raytracer 博文）
- **阴影 ≠ 视界**：阴影半径 ≈ 2.6 Rs（临界碰撞参数 b=3√3/2·rs）。
- **光子环 = 贴着阴影边缘的几像素亮带**（临界曲线处光堆积），外面跟着**指数衰减的次级子环**
  （光子多绕半圈再逃逸的更弱像）—— 结构感来自这里，不是粗环。
- **多普勒束射**：I_obs = g^4·I_emit，朝向观察者一侧更亮 → 不对称是真实感来源。
- **透镜本体 = 背景被弯折**：没有屏幕空间折射就不该用大光晕假装。

## 第 9 轮（bugfix）：黑洞渲染在所有东西前面 / 一直完美球形 / 闪光是黑的

### 根因（一个根因解释三处症状）
`src/gfx/scene.js` 的 `L5LensShader` 片元里有一句**实心黑盘**：
`if (b < bc) { gl_FragColor = vec4(0,0,0,1); return; }`。
该 pass 在 RenderPass **之后**跑 —— 在整幅画面上作画、**不带任何深度信息**。于是：
1. 把黑洞**前方**的水晶碎块与核心也盖成黑的（用户："独立于整个系统的渲染层级"）；
2. 它恒为正圆 → 把视界球被 `bhCrushField` 压出的凹痕全部遮住（"一直保持球形"）；
3. 闪光帧的中心同样被它盖住（"闪光那一下也是黑色的"）。

### 修法
1. **删掉黑盘**。遮挡交回给场景内的 `bhCore` 不透明视界球（`transparent:false /
   depthWrite:true / depthTest:true`，有正确深度：前面碎片挡它、它挡后面东西）。
   pass 只做背景弯折，从临界曲线向外 `smoothstep(0.0, 0.12, x)` 淡入。
2. 临界曲线按方位皱化：`bc = u_bh_r·(1 + u_bh_crush·0.12·(sin(3az+1.7)·0.6 + sin(5az−0.9)·0.4))`
   —— 常态正圆（无毛定理），只在挤压塌缩时被揉皱。新增 `u_bh_crush`，
   `syncFx` 签名加 `bhCrush = 0`，`main.js` 传 `l5._bhWarp ?? 0`。
3. **闪光期间不画黑球**（`l5Core.js`）：闪光段 `bhRDraw = BH_FLASH_R(0.20u)` → `bhCore`
   变成 0.133u 黑球杵在爆白中心并遮住身后。此刻已塌进奇点、**不存在视界** →
   `bhCore.visible = bhVisible && bhFlash <= 0.001`，闪光段只留加色 `bhLens`。

### 复用经验（★ 值得记住）
**RenderPass 之后的全屏 pass 里写"实心几何"（黑盘/遮罩/实心晕）= 绕过深度测试手动画优先级。**
任何"看起来悬浮在所有图层之上"的视觉 bug，先去全屏 pass 里找有没有 `.rgb = vec3(0.0)` 之类的硬写。
遮挡关系必须回到场景内的深度网格上（transparent:false / depthWrite:true / depthTest:true）。

### 自己踩的坑（语法检查拦下了）
写完注释 `旧版 \`if (b < bc) 输出纯黑\``——**GLSL 注释里的裸反引号**截断模板字符串，
`_syntax_check.mjs` 报 `scene.js FAIL @ line 76`。这是本项目第 5 次踩同一个坑。
规则：**GLSL 模板字符串内的注释禁止使用反引号**，改用引号或不用标记。

`node _syntax_check.mjs` 13 文件全过；坐标地图追加修订 #9。未构建 / 未截图 —— 验证由用户做。

## #17 v5.29：隐形遮挡体（invisible occluder）—— 洞前碎片真能遮住透镜了
