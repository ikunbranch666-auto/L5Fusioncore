## 黑洞体半径口径（v5.22-尺，定死）

- `BH_R_*` 一律是**整个黑洞的外径（含引力透镜光晕）**，不是事件视界半径。
- `bhLens.scale = bhRDraw`（外径；>80 顶在用户定标的 `BH_R_MAX = 0.40u`）
- `bhCore.scale = bhRDraw / BH_LENS_K`（视界 = 0.267u；与着色器 `u_bh_vh = 1/1.5` 自洽）
- 粒子吞噬判定：`s.pos.length() <= bhR / BH_LENS_K`（落在视界面上）
- ⚠️ 别再把透镜壳往外乘 `BH_LENS_K` —— 那会让外径变 0.60u，用户会立刻发现"大了好多"。

## 事件视界 ≠ 引力透镜

- `bhCore` = 不透明纯黑 ShaderMaterial（`transparent:false` / `depthWrite:true` / `depthTest:true`、
  顶点按 `bhCrushField` 内凹、`renderOrder 18`），遮住背后一切 —— **它是唯一有深度的遮挡者**。
- `bhLens` = 加色 ShaderMaterial（`renderOrder 26`、`depthWrite:false`），只画视界之外的光子环/光晕，不遮挡。
- 两者曾是同一个半透明球 → 能看见后面的水晶碎片，物理上是错的。
- ⚠️ **遮挡必须交回给场景内的深度网格**（2026-09-29 #9）。凡是在 RenderPass 之后的全屏 pass
  （`L5LensShader`）里写实心几何（黑盘/遮罩/实心晕），等价于绕过深度测试手动画优先级 ——
  会出现"黑洞渲染在所有东西前面""永远完美球形""闪光是黑的"这类症状。
  全屏 pass 只允许 `mix(base, col, strength)` 式的背景采样变换。
- **（2026-09-30 #12 定案）屏幕空间透镜 pass 已整段拆除** —— 它在本场景没能产生可见弯折，
  只剩压亮项 → 凭空一圈"画在所有东西前面的灰环"（用户从未要求）。
  **规则：新增任何全屏 pass 前，必须先在静止场景单独验证"核心效果确实可见"再接入管线；
  禁止把增亮/装饰项和未验证的核心效果捆绑上线。** 引力透镜最终方案需单独立项。

## 引力透镜最终实现（v5.27 落地 / v5.28 修正，已取代下面 v5.23/5.24 方案）

- **数据源**：黑洞中心的 `WebGLCubeRenderTarget(256, HalfFloat)` + `CubeCamera`，
  隔帧刷新、渲染时隐藏 `bhGroup` → 这才拿到"洞后到底有什么"。
  `l5.updateProbe(renderer, scene)` 由 main.js 在 sync 之后、stage.render() 之前调用。
- **形状**：**过洞心且垂直视线的薄圆环**（`RingGeometry(0.985, LENS_U_OUT, 128, 1)` billboard），
  不是球壳（球壳前半球比洞心近，会把洞前碎块一起涂掉），也不是圆盘（v5.27 的圆盘太厚）。
  `scale = bhRDraw / BH_LENS_K` ⇒ 几何内缘 u=1（临界曲线 = 视界球轮廓），外缘 u=1.25。
  面向相机：`onBeforeRender` 里 `q = parentQ⁻¹ · camQ` + `updateMatrixWorld(true)`。
- **数学**：`src/gfx/geodesic.js` 纯 Schwarzschild 零测地线积分（node 断言 15/15 通过）。
  尺度锚点：**临界曲线 = 视界球轮廓**，故 `rs_eff = (外径/BH_LENS_K)/b_c`，视觉尺寸不变。
  `u = b/b_c`；`LENS_RING_PHYS=0.015`（文献厚度/黑洞半径，别动）、
  `LENS_RING_FRAC=0.25`（实际厚度/阴影半径，唯一旋钮）、`LENS_U_OUT = 1 + FRAC`。
- **绘制顺序（v5.28 定）**：`bhGrav.renderOrder = 36`（结构层 29–34 **之后**，做真替换）、
  `bhLens.renderOrder = 38`（它的光子环正好落在透镜环里，必须排在透镜之后）。
- **防"凭空圆环"三道闸**（v5.24 被用户否的教训）：① 外缘把**偏折角本身**乘窗
  `1−smoothstep(1, U_OUT)`，不是把颜色混淡 → 环外缘输出自然等于未偏折结果，严格无缝；
  ② 高阶像 `exp(−max(α−π,0)·1.6)` 变暗 → 临界曲线附近不出噪点；③ 不进辐射链（noGlowMask）。
- **v5.29：洞前碎片遮挡 = 隐形遮挡体（invisible occluder / depth mask）**
  给水晶碎片做"只写深度、不写颜色"的孪生体：`colorWrite=false` + `depthWrite=true` +
  `transparent:true` + `renderOrder = 35`（夹在结构层 34 与透镜环 36 之间 ⇒ 只影响 36/38，
  其它层零影响）。**必须共享同一份 uniforms 对象引用**，`material.clone()` 会把 uniform
  value 深拷贝成冻结快照（顶点位移会和可见碎片错位）。
  资料依据：three.js r.71 起的官方"隐形但仍遮挡"答案；ibra-kdbra/black-hole 的
  world→color target + masks→mask target + composition 管线。
- **已知残余局限**：bhLens(38) 靠自身球面(0.40u)深度做 depthTest，而碎片被推到 0.16~0.34u
  （在球面内部）⇒ 前沿碎片挡不住光子环，光子环会浮在碎片之上。修法是改 bhLens 的深度基准。
- **v5.30：真替换必须靠 `depthWrite`，不能靠 `renderOrder`**（缺陷 A 修复）
  · 把 bhGrav 排在结构层之后（36）做"覆盖度 1 的替换"，代价是把它前面所有
    `depthWrite:false` 的层（coreMesh 30 / shellInner 31）**一起抹掉** —— 环像贴在外壳上。
  · 给那两层补 35 号隐形遮挡体是**错的**：它们几何上包住黑洞，近侧深度永远比洞心近
    ⇒ 环在中心区域完全消失，>80 就看不到透镜了。
  · 正解：`depthWrite:true`（写洞心深度）+ `renderOrder 20`（回到结构层之前）
    ⇒ 排在它之后的层按自身深度自动分流：比洞心远的被剔除（不混第二张像）、
    比洞心近的按 alpha 叠上（前景幽灵壳照旧可见）。两条要求同时成立。
  · **规则（可复用）**：凡"某层必须独占一个像素"的需求，用**该层的深度写入**实现，
    不要用排序实现；排序只能决定并列关系的先后，不能表达"谁该被丢弃"。
  · **连带**：环写深度后，闪光段不能再用 alpha 淡出（alpha→0 却仍写深度会在爆白中心
    挖出黑洞）⇒ 改 `visible` 整条关掉；`u_gv_amt` 已删，片元 alpha 恒 1。
  · **待验证**：洞后内容是否真被替换；35 号孪生体是否反而把 bhLens(38) 光子环挡过头。
- ⚠ 别再"加大光晕/提高增益"去假装透镜 —— 用户两次因此定性为"闪瞎眼""凭空多出的圆环"。
- **v5.28 两条硬修正（用户两记重锤）**
  ① **厚度必须对齐物理量**：`LENS_RING_PHYS = 0.015`（文献：第一层光子环厚度/黑洞半径）
     常量化，再并列 `LENS_RING_FRAC = 0.25`（实际取多少）。禁止凭手感给厚度。
     现口径 环宽 0.0667u≈7.5px / 黑洞直径 60px / 夸张 16.7×（v5.27 是 53×，被否）。
  ② **覆盖度恒为 1，做真替换**：用 alpha<1 把弯折像与直影像 crossfade = 一个像素两张像
     = 物理错误。"远处看不出透镜"必须靠**偏折角本身趋于 0** 实现，不是靠两张图半透明叠加。
     故 bhGrav.renderOrder = 36（结构层之后），bhLens = 38（它的光子环正好落在透镜环里）。

## 引力透镜设计原则（2026-09-29 调研定案，v5.23-lens）

- 调研来源：Gargantua（Kerr 测地线渲染器）/ EHT M87* / Schwarzschild raytracer 博文。
- 光子环 = **贴着阴影边缘的几像素亮带**（临界曲线 b=3√3/2·rs），外面跟着指数衰减的次级子环；
  多普勒束射（一侧更亮）是不对称感来源；**透镜本体 = 背景被弯折**，没有屏幕空间折射就
  不该用大光晕假装 —— 粗环 + 大 halo + 高增益 + bloom = "闪瞎眼"（用户实测截图定性）。
- 真做测地线积分每像素太贵且无 post-pass → 本项目折中：不透明黑球 + 细环 + 子环 + 多普勒。
- **v5.24c 用户定标**：① 透镜只弯折**黑洞后面**的内容 —— 黑洞与相机之间的碎块/核心/粒子
  不参与弯折，照常遮住黑洞（靠 `DepthTexture`：窗口深度 ≤ 黑洞近侧表面深度的像素一律原样输出）。
  ② 透镜是**薄薄一层**（`BAND=0.26`，临界曲线外 26% 半径），层内是被压缩的身后场景；
  偏折量在临界曲线处最大、向外 exp 急衰。**不要做大面积背景扭曲**（旧版采样到 3.3·bc 被否）。
- 全屏 pass 拿不到"前后"概念 → 想分前后必须挂 DepthTexture；两张 RT 必须各用独立的一张
  （共用会在同一次 draw 里既采样又写入 = feedback loop）；`tDiffuse/tDepth` 按当前 readBuffer 取。

## 回落/塌缩的演出原则（用户定标）

- 回落 <80 必须三段：压入奇点（oblate 压扁 + 扭曲，**非等比**）→ 膨胀到当前能量对应尺寸 →
  外壳"数据流虚影→实体"成形并浮升到位。任何"同帧全体瞬移/重排"（外壳、粒子）都是灾难级差评。
- normal 态的连续量一律**指数平滑跟随**目标，禁止硬切；跨阈起点取 `bh.lastR`（每帧落盘的当前半径）。
