# AETHER-NODE // L5 动力聚变核心 · 实时展示终端

依据 `L5_fusion_core_implementation_spec.md`（`v2.0-IMPLEMENTATION-BASELINE`）实现的单页前端展示应用。
**整个界面只为展示 L5 服务**：主视窗为常驻的 L5 实时渲染，五个副屏全部是 L5 自身的规格展开。

## 运行

```bash
cd l5-core-showcase
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # 产物输出到 dist/
```

技术栈：原生 ES Modules + Vite + three.js（仅用于正交相机 / 自定义着色器 / EffectComposer 后处理）。

## 规格落地要点

- **几何**：内层 `R_core = 0.8u` 固态发光十二面体（`depthWrite = true`，renderOrder 30）；外层 `1.0u` 半透明电磁约束框，壁厚 `0.04u`（renderOrder 31，`depthWrite = false`）。
- **数值链**：`I_core = 1.2 + 2.8·p^1.5` → `E0 = min(I_core, 3.5)` → `E(t) = E0 × [1 + 0.12·Φ]`；上钳作用于 **E0** 而非 E(t)，因此 OVERDRIVE 期间呼吸仍保留在 `[3.50, 3.92]`。
- **色彩**：按 **RGB 分量线性插值** `#00F2FE ↔ #FF7700`（禁止 HSV 色相角插值），结果转换到线性空间后写入 uniform。
- **时间**：全部取自 `MasterClock.simTime`，`deltaTime` 钳制 `0.0333s`，平滑插值一律用 `1 − e^(−k·Δt)`；呼吸相位以累加方式推进，周期切换无阶跃。
- **渲染管线**：`ACESFilmicToneMapping`（Exposure 1.0）+ `UnrealBloomPass(0.85 / 0.45 / 1.0)` + `OutputPass`，输出 sRGB。
- **三级钳制**：输入层 `setTelemetryValue`（含 `typeof number` 校验与 `Clamp`）→ 物理层 `Math.min/max` → GPU 层着色器内 `clamp(u_main_param, 0.0, 1.0)`；副屏「约束与验收」可直接注入 `1.7` 做钳制审计。
- **不可牺牲红线**：L5 的颜色与明度呼吸映射在任何路径下均不降级。

## 展示辅助项（非规格项）

- **视口缩放**：规格基准为 `1.00×`（`H_world = 20.0u`）。默认 `2.50×` 便于观察，`1.00×` 可一键回到规格视口。
- **展示模式**：自旋 + 两级视差（`K₅ = 0.90`），默认开启；dock「规格严格」可关闭（§7.3 口径 `u = v = 0`）。
- 检测到 `prefers-reduced-motion: reduce` 时，几何微抖动归零并禁用自旋/视差，仅保留发光呼吸（41.3 / 10.1.2）。

### v3：为什么之前「看不出来」，以及改了什么

首版改造后仍然"看不出来"。用**像素探针**（见下节）把「看得见与否」量化，逐一定位了五个根因：

| # | 根因 | 量化证据 | v3 修正 |
| :-- | :--- | :--- | :--- |
| 1 | **整帧过曝**：约 10 个加色层叠加后核心 HDR ≈ 5，ACES 把 >4 的输入映射到 ≥0.97 | 核心 `cv=0.0014`、`localContrast=0.00023`、`DR=1.01` —— 纯白平块 | 建立**显式光照预算**：`u_plasma_gain / u_field_gain / u_shell_gain / u_rod_gain` 各层独立配额 |
| 2 | **两层薄壳离核心太近**：默认视口 1u ≈ 81px，0.86/0.92u 仅比核心轮廓外扩 **5px / 10px** | `layerPx` = core 65 / fieldA 70 / fieldB 75 | 薄壳**外移到 1.16u / 1.38u**（硬壳之外、背景之上），层间距 ≥13px，且它们不再骑在发亮的核上 |
| 3 | **面板缝是亚像素宽**：物体空间线宽 0.055 → 实际约 0.3px | `edge.strongFrac = 0` | 改用 `fwidth` 归一化的**像素级格线** `gridLines()`，任意缩放恒为 ~2px |
| 4 | **Bloom 把细线的能量摊满全画面**：等离子核心本体仅 0.16~0.45 HDR，远低于阈值 1.0；真正喂饱 bloom 的是超过 1.0 的发光棱与面板缝细线 | 关 bloom 后 `cv` 0.073→**0.348**、`DR` 1.27→**3.72** | 棱 / 缝 / 高光压回阈值以内，只让等离子体丝作为唯一合法的"过阈值热源"选择性发光 |
| 5 | **明度线性跟随 E(t)**：IDLE→OVERDRIVE 亮度涨近 3 倍 → 直接进入压平区 | `cv` 从 IDLE 0.135 跌到 OVERDRIVE 0.017 | 统一**压缩映射** `eC = 0.60+0.75·pow(E/3.5, 0.55)`、`pC = 0.55+0.45·pow(p, 0.70)`（严格单调，63.2 仍成立）；能量差额交给**辐射外溢 / 粒子 / 湍流频率 / 色相**表达 |

> 顺带修正的两个正确性问题：正交相机下 `normalize(-mvPosition.xyz)` 是**错误**的视线方向（摄影机
> 专属），会让边缘光算歪 —— 改为显式传入 `u_cam_forward`；溢出闸门上界由 `2.0` 改为规格封顶 `3.5`，
> 否则 ACTIVE_ENGAGE（E0=2.19）就已满溢，两态之间没有梯度。

### 实测量化结果（1262×648 / dpr 1 / zoom 2.5，预热 240 帧确定性推进）

| 指标 | 含义 | 规格字面档 | IDLE | ACTIVE_ENGAGE | OVERDRIVE |
| :--- | :--- | ---: | ---: | ---: | ---: |
| `core.cv` | 核心内湍流方差 | 0.080 | 0.183 | 0.243 | 0.175 |
| `core.localContrast` | 3×3 局部对比（丝状结构） | 0.0136 | 0.042 | 0.055 | 0.034 |
| `core.dynamicRange` | p95/p05 | 1.14 | 1.90 | 2.36 | 1.83 |
| `edge.strongFrac` | 可见硬边缘占比 | 0.121 | 0.291 | 0.380 | 0.254 |
| `energy.outsideRatio` | 体外能量占比（外溢辐射） | 0.133 | 0.113 | 0.128 | 0.266 |

差分验证（同一帧开关单个图层）：关掉两层约束场后，u=1.09 / 1.19 处亮度下降至原先的 29% / 25%
（即薄壳在该处以 +248% / +301% 的相对量清晰可见）；关闭 bloom 后核心 `cv` 由 0.175 变为 0.198
—— 差距已从上版的 4.8 倍收敛到 1.13 倍，说明 bloom 不再抹平结构。

跨缩放稳健性：zoom=1（1u≈32px，核心半径仅 26px）下 `edge.strongFrac` 仍为 0.315 —— 像素级格线
宽度未随缩放退化。

### v4 / v4.1：面局部板材 · 展开机构 · 抖动重构（本轮）

针对反馈「外壳是直白条 / 内壳是方格，突兀不科幻」「像 2D 贴图」「高能抖动像画面 bug」「要激发态变化」：

| # | 反馈 | 根因 | v4 修正 |
| :-- | :--- | :--- | :--- |
| 1 | 直白条 / 方形网格 | 三轴世界空间网格不跟随五边形拓扑 | **面局部坐标系**：由面法线构建正交基，把片元位置投成面内 2D 坐标，五边形 SDF（`sdPentagon`）生成装甲板（3 圈同心板 + 辐条 + 铆钉）与散热格栅，缝天然贴合五边形 |
| 2 | 2D 贴图感 | 白线是加色的，没有遮挡力，也没有厚度 | 缝改**真凹槽**（预乘 alpha 抬高遮挡 + 本体压暗）+ `panelHeight` 高度场求**凹凸法线**（板材真的立起来）+ 倒角高光 + 每板随机色差 |
| 3 | 高能抖动生硬 | 20Hz 规格标量直接塞进 xyz = 整体沿固定对角线刚性滑动 | 标量只作**幅值**：经二阶欠阻尼跟随器（K=190, ζ=0.72）+ 缓慢游走的 3 轴方向 + 姿态微摆，读作"悬浮体颤动" |
| 4 | 无激发态变化 | 内外壳永远是闭合同心体 | **p ≥ 0.74 触发展开**：12 块内壳花瓣以铰链 Group 外推+翻转成爆炸视图（几何标定 r∈[1.09,1.38]，嵌在两层约束场之间），露出 12 片散热鳍 + 2 道倾斜约束环；欠阻尼弹簧推进，到位回弹；外壳沿棱出现定向**边缘粒子流**（`L5EdgeFlow`，30 条棱上流动而非随机散布） |

**v4.1（本轮回最重要的一课）**：v4 提交后像素探针显示画面仍只有线框。抓取浏览器控制台发现
**壳体片元着色器自始编译失败**（`modelMatrix` 片元不可用 / `rad` 未声明），three.js 静默跳过该材质
—— 整个板材系统从未渲染过。修正：切线基在顶点着色器变换到世界空间经 varying 传入，片元拼装
凹凸法线；同时把面朝相机的 alpha 从 ~0.06 提到 0.30~0.50（预乘混合下 alpha 才是遮挡力），
板缝改为**能量渗光缝**（沿缝慢速能量脉冲），修后 `meanLinear` 提升 2~4 倍、
`edge.strongFrac` +45%，花瓣展开（`deploy.d`: 0 → 0.32(0.8) → 0.77(0.85) → 1.0(≥0.9)）在画面上可读。

新增几何工具 `src/gfx/dodecaKit.js`（12 面法线 / 20 顶点 / 面多边形 / 花瓣铰链 / 棱段表 / 散热鳍），
带纯 node 自检脚本（12 花瓣、30 棱、鳍不穿核心 0.8u）。

### v4.3：子代理深度重构（场层实现方式 · 花瓣折返 · 环流彻底重做）

用户圈图第三轮反馈：白条仍在（怀疑实现方式）、展开处片状长条 + 双壳叠乱、环流动效敷衍。
由子代理执行三轮"改→建→无头探针→读图"迭代：

| # | 问题 | 根因 | v4.3 修正 |
| :-- | :--- | :--- | :--- |
| 1 | 白条仍在 | 约束场是**多面体网格**：逐面法线在棱处跳变，任何纹理调制都救不了掠射面上的离散亮条 | 场层换**平滑球体**（SphereGeometry 64×48，非规格增强项几何自由）；薄膜 = 宽菲涅尔底亮 + 锐边环 + 振幅 ≤0.10 的软呼吸 + 大尺度软扫描带（波长 > 球径，物理上无法成条） |
| 2 | 片状长条 + 双壳叠乱 | 花瓣翻开仅 0.35rad + 外推，终态像"第二个一样的十二面体"叠在原壳上；近侧向视角下是透光薄片 | **折返展开**：OPEN_ANGLE=0.60 + push=0.035（数值扫描标定 rmax=1.449u，守住不撞取景的红线；用户口头建议的 0.8~2.4rad 折返区间经扫描 rmax 高达 1.58~1.99u，数学上不可行）；花瓣加 `u_petal` 分支：实心度 +0.24、边缘渗光勾边、12° 同向 yaw 鳞甲错位 —— 展开态读作"装甲板折靠舱体"，与闭合壳轮廓明显不同 |
| 3 | 环流敷衍（2 个方点） | 环是普通 torus + PointsMaterial 方点 | **彻底重做**：导管 = 自定义着色器（细芯线 + 白热芯 + 柔外辉 + 3/4 个沿周流动脉冲包 + 轴向闪烁）；粒子流 = 每环 240 颗全 GPU 解算的软圆精灵（aTheta0/aSpeed/aJitter/aSize/aSeed，`gl_PointCoord` 径向衰减，绝无方点）；**入场动画** = u_form 由展开 ease 驱动，粒子从 2.6u（画面外）螺旋汇入，粒子汇成流后导管才点亮（smoothstep(0.55,1.0,u_form)），两环错峰 |

验收：探针 11 工况 + 4× 截图目检 —— 闭合态无白条/无角板（两层光滑球膜光晕）；展开态无薄片、折返板与闭合壳轮廓明显不同；K_form 中间态拍到粒子汇流形态。`edge.strongFrac` 无回退。

**碎裂几何的实现要点（踩坑记录）**：

- **参数空间网格三角化**：每片是 (a,t) 参数空间的一个矩形单元，直接铺规则网格再经 `warp` 映射。
  此前两次失败：① 绕质心缩放做内嵌环 —— 外缘板片是弧形板（香蕉形），缩放环自相交，
  三角面积比轮廓大 10~45%；② 质心扇形填充 —— 香蕉形的质心可能落在形外，扇形三角大面积重叠
  （实测只覆盖自身轮廓的 0~57%）。参数空间矩形 + 同胚映射则**必然严丝合缝**。
- **(a,t)→(x,y) 是反向映射**（雅可比行列式 = −r < 0）：参数空间的逆时针网格到笛卡尔空间是
  顺时针。必须反绕，否则整片背向相机 → `gl_FrontFacing=false` → 着色器把外法线翻成朝内，光照全反。
- **共享边界用全局采样表**：所有环带的角向断点 ∪ (断点±δ) ∪ 五边形顶点方位 ∪ 24 等分均匀栅格
  构成全局方位表；每片只取自己区间内的那一段。若各片自行细分，共享边界两侧点列不一致，
  弦损失会变成真实缝隙。验收：蒙特卡洛实测覆盖率 **100.00%、重叠 0.00%**。
- **闭合态面积守恒恒等式**：Σ片面积 == 12×五边形面积（0.8762），任何重构后先跑这条再谈视觉。

### 渲染探针（`?probe=1`，headless 验证用）

`?probe=1` 时在最后一帧渲染完成后用 `gl.readPixels` 回读默认帧缓冲，在页面内统计后写入
`<script id="__probe" type="application/json">`。提供的判据：

| 指标 | 对应的视觉问题 |
| :--- | :--- |
| `core.cv` / `core.localContrast` | 等离子湍流丝是否成形（纯色块 cv≈0） |
| `rings[]` 径向亮度剖面 | 各层是否在径向上留下可读台阶 |
| `edgeProfile[]` / `edge.strongFrac` | 面板缝 / 棱 / 薄壳边缘的局部对比 |
| `energy.outsideRatio` | 硬壳轮廓外的能量占比 = 外溢辐射 |
| `peaks[]` | 径向剖面上的结构性羁点 |

`?probeWarm=N` 会在一个真实帧内同步推进 N 帧仿真（默认 240，60fps = 4s）后再采集 ——
无头环境每页只有约 2 个真实帧，rAF 计数方式不可靠，必须靠同步预热才能得到确定性画面。

配套脚本：`../../headless_probe.mjs`（内置静态服务 → 无头采集 → 抽 JSON）、
`../../probe_diff.mjs`（两帧差分，量化单个图层的可见贡献）。
