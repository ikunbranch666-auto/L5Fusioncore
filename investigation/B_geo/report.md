# B_geo 调查报告：碎块几何结构 × 相机视角关系

> 任务：解释"为什么白块与碎块身份/内外位置相关"。
> 方法：只读源码（dodecaKit.js / l5Core.js / main.js / scene.js），所有数字给出推导。
> 行号均指 `src/gfx/l5Core.js`（简称 Lxx）、`src/gfx/dodecaKit.js`（简称 Dxx）、`src/gfx/scene.js`（Sxx）、`src/main.js`（Mxx）。

## 0. 结论先行（TL;DR）

"白块"不是单一原因，而是**三条互相独立的几何/光学轴**叠加的结果。碎块身份（band 几、哪一面、该面内侧还是外侧）在这三条轴上的位置不同，白度就不同：

| 轴 | 决定什么 | 谁白 | 谁不白 |
|---|---|---|---|
| **A. 屏上投影是否压在核剪影上** | 背后有没有核光可透 | band0/band1 面心楔块（屏上偏移 ~0.49–0.67，落在核剪影半径 0.64 内）→ 核 deployed 亮度 ×4.5 透过来，stored=0 也白 | band3 外缘大板（屏上偏移 0.78–0.89，落在核剪影外的环带）→ 背后没有核，只有自己被钳到 ≤0.85 的本体色，stored 再高也白不了 |
| **B. 面朝向（ndv）** | fres/透射/边光的分配 | 掠射面（ndv≈0）：`pow(1-ndv,3.5)` 边光=1、alpha=0.90，轮廓圈一圈自亮 | 正对面（ndv≈1）：边光≈0，靠透射项 `(1-fres)` ≈0.95 发光 |
| **C. 深度剔除** | 核不透明，写深度 | 朝向面碎块（核之前）正常绘制 | 背面碎块凡是投影落在核剪影内的，深度测试失败被丢弃——**根本不参与该像素的合成** |

一句话：**band0 白是因为它们正好坐在亮核前面（A 轴），band3 打不白是因为它们在核剪影外的环带里、背后是黑的（A 轴），stored/u_cool 只做冷蓝染色（红绿压暗），没有把碎块顶白的能力（L1264–1267）。**

## 2. l5Core.js：半径体系与每带展开位置

### 2.1 半径常量（L31–L34, L352–L353）

| 量 | 值 | 含义 |
|---|---|---|
| R_CORE | 0.8 | 等离子核十二面体外接半径（顶点距离）；其面内切平面 = 0.8·0.79465 = **0.636** |
| R_SHELL_OUT | 1.0 | 碎块母十二面体外接半径（顶点距离 1.0） |
| SHELL_WALL | 0.04 | 壁厚 |
| R_SHELL_IN | 0.96 | 基准面 shellInner 外接半径；面内切平面 = 0.96·0.79465 = **0.763** |

碎块几何原点 = 面心，沿 n 距原点 1.0·0.79465 = **0.7947**；板厚 [−0.012, +0.018] → 闭合态碎块沿 n 占据 **[0.783, 0.813]**。
基准面（0.96 母十二面体）沿 n 在 **0.763**——即碎块底面 (0.783) 比基准面平面 (0.763) 还靠外 ~0.02u，夹在 0.04 壁厚环内（L2813–2818 注释："底面贴基准面、顶面距基准面=壁厚"）。

### 2.2 运动模型（L2820–L2831）——只有沿法线的平移

```
off   = eP · f.pushAmt + sin(ωt + φ)·floatAmp      (L2827–2828)
pos   = faceCenter + n·off                          (L2830)   ← 纯径向推出，无切向位移、无自转位移
bob   = 沿 y 方向叠加 ±floatAmp·0.45                (L2829/L2831)
```

- `eP` = 该片自己的 smoothstep(d/arrive)，d=u_deploy 全局展开进度（L2767–2782）。
- **pushAmt = 0.30 − 0.14·sN + 0.05·jit**（D695），sN = 本片面积/本面最大面积。
  → **小碎片推得远、大板推得近**（L2900 注释 0.16~0.34u）。
- arrive ∈ [0.46,1.0]（D700），轻碎屑先到位。

### 2.3 每带展开后径向位置（u_deploy=1，数字由 1.2 表 + pushAmt 推导）

| band0 | 0–0.24 | ~0.31 | **1.106** | 0–0.15 | **1.106–1.115** | 否 |

| band2 | 0.47–0.72 | ~0.24 | 1.036 | 0.23–0.44 | 1.062–1.125 | 否 |

- BASE_LIFT = 0.10u，高能态沿面法线抬升，浮动 ±32% → 沿 n 在 0.763+0.068~0.132 ≈ **0.83–0.89**。

## 3. 相机：视线链

### 3.1 相机参数（S160–162, S26–28, S283–288, M232–238）

- **正交相机**（非透视！）：near 0.1 / far 100，位置 (0,0,50)，lookAt 原点（S160–162）。
- H_WORLD=20.0，默认 zoom=2.5 → 竖直可见 20/2.5 = **8.0u**（半高 4.0u，S283–287）。
- 轴测倾斜：assembly.rotation.x = +15°，rotation.y = −10°（S170–171）。

### 3.2 相机在 l5 局部坐标中的视线方向

assembly 旋转 = Rx(+15°)·Ry(−10°)，求逆得相机局部位置方向：

```

view ray      = ( -0.168, -0.259, -0.951 )
```

### 3.4 视线链：闭合态 vs 展开态

**关键渲染顺序**（L1891–1947, L1999–2007）：
- 核 L5_Core：**不透明**、depthWrite=true、renderOrder 30（L1883–1893）→ 最先画并写深度。
- 基准面 shellInner：renderOrder 31，预乘透明。
- 碎块本体：renderOrder 32，depthTest=true / depthWrite=false。
- 碎块内芯 L5_FragCore：renderOrder 34，加色。
- 混合：blendSrc=One / blendDst=OneMinusSrcAlpha（L1876–1878）→ **dst = src.c + dst·(1−src.a)**。

```
=== 闭合态 (u_deploy=0, p=0.35~0.80) ===
相机 → [前碎块板 0.78-0.81] → [基准面前面 0.763] → [核前面 0.636] —— 核不透明，深度写在 0.636
像素落在核剪影内(半径~0.64-0.8)：
  合成链(前→后绘制顺序=后→前叠加)：
    核色 C_core (contain=0.22, 暗)            ← L1578 CORE_CONTAIN_LO=0.22
      → 基准面 a≈0.43(groove处~0.95) + 板缝渗光 L1412 + 五边形边光 ×(1+1.15·closed) L1424
      → 前碎块 a≈0.44(正面)/0.72(掠射)，c 里 seamEdge 轮廓线 ×(1+0.9·closed) L1435
  背面碎块：深度 > 核深度 → 深度测试失败 → 被丢弃，不参与合成。
像素落在核剪影外的环带(0.8~1.0)：
    射线打不到核 → 无深度写入 → 后碎块、后基准面、前基准面、前碎块全部参与，
    back-to-front 逐层 预乘叠加；底色黑。

=== 展开态 (u_deploy=1, p>0.80) ===
相机 → [前碎块沿n 0.98~1.11] → [基准面抬到0.83-0.89, 幽灵a≈0.09~0.20] → [核前面 0.636]
  contain=1.00（CORE_CONTAIN_HI, L578）→ 核亮度 ×4.5；coreExpose≤1.15。
像素落在核剪影内：
    C_core(亮,~0.2-0.3 线性) → 基准面幽灵(被fade×0.40、wipe×0.50压暗)
      → 前碎块 a≈0.62(正面)/0.90(掠射)；碎块后面的背面碎块仍被核深度剔除。
像素落在环带(0.8~1.2)：
    无核；黑底 + 后层碎块 + 前层碎块预乘叠加。
```

### 3.5 谁挡谁：同一视线穿过多层时的层级

1. **核剪影内**：只有"相机侧"的碎块/基准面可见；背面同一块碎块被核深度剔除（C 轴）。
2. **环带内**：前碎块(32) 与后碎块(32) 同 renderOrder，three.js 按 z 后→前画；预乘混合下后层先画、前层盖。前碎块 alpha 越高（掠射 0.90），后层被压得越狠。
3. **基准面 vs 碎块**：基准面 renderOrder 31 < 碎块 32 → 基准面永远先画、碎块画在它上面；闭合态靠碎块低 alpha (0.44) 透出基准面轮廓线（L1230–1231 注释）。

## 4. 法向/朝向：fres 透射与边光的片间差异

### 4.1 展开态下面向镜头的碎块 ndv 分布

- **正面 3 面（face 4/8/9）上的全部片**：ndv ≈ 0.72–0.90。
  - `fres ≈ 0.05–0.056` → alpha ≈ 0.62（展开）。
  - **L1035 透射项** `(1−fres) ≈ 0.94–0.95`：这些片的"体内散射"项几乎满值发光。
  - **L1165 边光** `pow(1−ndv,3.5) ≈ 0–0.012`：≈0，不吃边光。
  - **L1159 断口光** `pow(1−ndv,3.0) ≈ 0–0.025`：≈0。
- **掠射/剪影 6 面（face 0/1/2/3/5/6）上的全部片**：ndv ≈ 0–0.28。
  - `fres ≈ 0.31–1.0` → alpha ≈ 0.69–0.90。
  - L1035 透射项 `(1−fres) ≈ 0–0.69`：几乎不透明、不透射。
  - **L1165 边光 = 0.32–1.0**、L1159 断口光 = 0.02–1.0：这些片自己加边光/断口光发亮。
- **背面 3 面（face 7/10/11）**：可见的是朝镜头的内面（法线 −n），ndv≈0.72–0.90，光学行为同正面；但投影落在核剪影内的部分被核深度剔除，只有环带部分可见。

### 4.2 预测：哪些片 fres 高/低

- **fres 高（≈1，白亮边缘）**：投影落在十二面体剪影圈上的那一圈片——即 face 1/2/3/6（spin=0 时），且主要是这些面上 **band3 外缘大板**（它们在最外圈，决定剪影）。
- **fres 低（≈0.05，透体内光）**：face 4/8/9 正面的全部片，**尤其 band0 面心楔块**——正对视点 + (1−fres) 透射满值 + 背后是亮核 = 最容易白。

## 5. 半透明叠加估算（alpha 0.42~0.92）

### 5.1 核亮度量级（L1513–1594）

- `u_plasma_gain = 0.12`（L1856，刻意压暗）；体积 raymarch 32 步、u_density=7.0（L1796–1797）。
- 发射项（L1548–1550）：`emit = u_emissive_color·eGain·(0.45+1.55·fil)·(0.70+temp)·0.34`，eGain=0.60+0.75·√eN（eN=E/3.5，满能量≈1.35）；白热丝 L1550 = `vec3(1)·eGain·0.10·fil·temp²`。
- 软膝 CORE_KNEE=0.95、渐近峰值 1.70（L585–586）。
- 数量级：闭合态 C_core ≈ 0.12·acc·0.22 ≈ **0.02–0.05（暗）**；展开态 ×1.0·1.15 ≈ **0.1–0.25（亮 4–5 倍）**。

### 5.2 "像素→光源"链与透射亮度

预乘公式 `out = src.c + dst·(1−src.a)`，穿 1 层前碎块（a≈0.62 正面）后，背后光源保留 38%；穿 2 层保留 38%²≈15%。

| 状态 | 像素位置 | 链 | 透过碎块后的核光量级 |
|---|---|---|---|
| 闭合 p0.35–0.80 | 核剪影内 | C暗(0.03) → 基准面缝光 → 前碎块 a0.44 | 0.03·(1−0.44) ≈ **0.017**——核几乎不贡献；白来自基准面板缝/五边形边的闭合态 ×(1+0.9~1.15) 加亮（L1424/L1435），**与 band 无关，内外都有** |
| 展开 p>0.80 | 核剪影内（band0/band1 投影处） | C亮(0.15–0.25) → 基准面幽灵(a0.1) → 前碎块 a0.62 | 0.2·0.9·0.38 ≈ **0.07** + 碎块自身 L1035 透射项 innerCol·(1−fres)≈0.95 |
| 展开 p>0.80 | 环带（band3 投影处） | 黑底 → 后碎块 → 前碎块 | **没有核光**；亮度=碎块自己的 c，本体已钳 ≤0.85（L1130）、终值软钳 1.5（L1326） |

### 5.3 基准面在链中的位置

- 闭合态：基准面在核与碎块之间（0.763 < 碎块 0.783），半透明、板缝自发光，是闭合态白的主要光源。
- 展开态：基准面抬到 0.83–0.89 并 fade 到幽灵（×0.40×0.50），**退居次要**；碎块沿法线飞到 0.98–1.11，确实飞离了基准面。

## 6. 屏幕→碎块身份映射操作指南（无头实测子代理可直接照做）

### 6.1 入口

`window.__AETHER_L5__` 在 main.js L721–725 已暴露：`{ l5, stage, mainParam, clock, ... }`。
**`l5.fragments` 直接可读**（L2009 返回对象 = `{...dodecaKit碎片记录, mesh, core, mat, stored, impactW}`），无需另找替代路径。

每片可用字段：
- 身份：`f.band`（0–3）、`f.faceIdx`（0–11）、`f.idx`、`f.seq`、`f.azimuth`、`f.radialN`
- 朝向：`f.normal`（面法线，l5 局部坐标）、`f.faceCenter`
- 运行时：`f.mesh.position`（局部）、`f.stored`、`f.impactW`、`f.mat.uniforms.u_cool.value`（=当前冷色偏移，L2841）

相机：`window.__AETHER_L5__.stage.camera`（OrthographicCamera）。

### 6.2 投影成屏幕坐标（CDP Runtime.evaluate 里执行）

```js
(() => {
  const A = window.__AETHER_L5__;
  const { l5, stage } = A;
  const cam = stage.camera;
  // 借一个现成的 Vector3 实例（避免 THREE 未全局暴露）
  const v = l5.group.position.clone();
  const q = l5.group.quaternion.clone();
  const out = [];
  for (let i = 0; i < l5.fragments.length; i++) {
    const f = l5.fragments[i];
    f.mesh.getWorldPosition(v);            // 世界坐标（已含 assembly 15°/-10°/自旋/视差）
    v.project(cam);                        // → NDC [-1,1]
    // stage.viewport.width/height 是 CSS 像素；乘 dpr 得 framebuffer 像素
    const px = ( v.x * 0.5 + 0.5) * stage.viewport.width  * stage.viewport.dpr;
    const py = (-v.y * 0.5 + 0.5) * stage.viewport.height * stage.viewport.dpr;
    f.mesh.getWorldQuaternion(q);
    const nWorld = f.normal.clone().applyQuaternion(q);   // 世界空间面法线
    // ndv：法线 vs 视线方向（相机朝向）
    const fwd = cam.getWorldDirection({});
    const ndv = Math.max(0, nWorld.dot(fwd));
    out.push({
      i, band: f.band, faceIdx: f.faceIdx,
      sx: Math.round(px), sy: Math.round(py),
      stored: +f.stored.toFixed(2),
      u_cool: +f.mat.uniforms.u_cool.value.toFixed(3),
      ndv: +ndv.toFixed(3),
      r: +v.length().toFixed(3)
    });
  }
  // 按屏幕 y/x 排序打印，或存 window.__FRAG_MAP 供比对
  window.__FRAG_MAP = out;
  return out;
})()
```

### 6.3 操作要点

1. **必须在渲染之后取矩阵**：`getWorldPosition` 读的是上一帧的世界矩阵。CDP 里先 `Runtime.evaluate` 触发一帧（或等 rAF），再执行上面代码；自旋使每帧位置微变，比对白块像素时应**冻结时钟**（`A.clock.setPaused(true)`，main.js L507 有此 API）再截屏+取映射。
2. **白块像素归属**：截屏后把可疑白点 (px,py) 与 `__FRAG_MAP` 里最近的 `(sx,sy)` 配对；用 `band/faceIdx/ndv/stored` 验证本文预测——
   - band0/band1 且 ndv>0.6 且 stored≈0 → 预测"核透出白"；
   - band3 且 ndv<0.3 → 预测"掠射边光白"；
   - band3 且 ndv>0.6、stored 高却不白 → 预测"环带无核光，stored 顶不白"。
3. **改能量/展开态**：`A.mainParam.setTelemetryValue(0.95)`（M499）；?p=0.9&instant=1 可在 URL 直达（M631）。
4. **每片材质克隆**：改 `f.mat.uniforms.u_cool` 只影响该片（L1983–1998），可用 `?stored=N` 全局强置（M646–649）。

## 7. 对"待解释现象"的逐条几何结论

1. **p>0.8 展开态，band3 某些片怎么打都不白（stored 高也白不了）**：
   这些片投影落在核剪影外的环带（屏上偏移 0.78–0.89 > 核剪影半径 0.64），背后没有核光；它们的亮度只有本体色（L1130 钳 ≤0.85）+ 被 stored 染色的冷蓝（L1265：c 乘 (0.74,0.86,1.0)，**红绿压暗**；L1266 仅加 (0.07,0.12,0.20)·u_cool，封顶 0.5 → +0.035/0.06/0.1）。stored 的物理作用是"变冷变暗蓝"，不是"变白"。
2. **有些内部碎块 stored=0 也是白的**：
   band0（及 band1 靠内）面心楔块投影压在核剪影上（屏上偏移 0.49–0.67 < 0.64），展开态核 contain 从 0.22→1.0（×4.5），经碎块 alpha≈0.62 后仍保留 ~0.38 的核光；叠上 L1035 透射项 (1−fres≈0.95)。白来自背后的核，与 stored 无关。
3. **p 0.35–0.80 闭合态内外都有发白**：
   此时核 contain=0.22 很暗，白来自**基准面板缝/五边形边框在闭合态的定向加亮**（L1424 ×(1+1.15·closed)、L1435 ×(1+0.9·closed)）——这些亮线在所有 band、所有面上统一出现，透过 a≈0.44 的半透碎块被看到，所以内外都白。
