# D_time — 后处理链路与时序：稳态白 vs 瞬时脉冲白 判定报告

> 只读分析：`src/main.js`、`src/core/mainParam.js`、`src/core/photometry.js`、`src/core/fsm.js`、`src/gfx/scene.js`、`src/gfx/l5Core.js`。未修改任何源码。
> 口径：用户「白块」= 探头像素口径亮度 >150/255 且 R>140 且 B>140（sRGB 输出，0–255）。

---

## 0. 一页结论

1. **后处理不会把中高亮度拉成 255 纯白。** L5FxShader 里有一道 Reinhard 软膝（knee=0.85，渐近上限 1.40 线性，scene.js L126-131），它跑在 OutputPass 的 ACES **之前**。于是全帧最亮像素（线性 ≈1.5）经软膝→1.15→ACES→sRGB ≈ **0.92（235/255）**，永远到不了 255。ACES 曲线本身在低段很陡：**线性 0.20 → sRGB 0.58（149/255）**，线性 0.50 → sRGB 0.81（206/255）。用户看到的「白块」绝大多数是**线性 0.2–0.85 的本征亮面**被 ACES 抬亮，不是过曝烧穿。
2. **Bloom（阈值 1.0 线性）只打在细发光线上**（轮廓脉冲环 / 爆发 / 命中环），不打在壳体本体上——晶体本体在 L1128-1131 被硬钳到 0.85 线性，基准面在 L1497-1498 钳到 1.25。
3. **`u_cool`（stored 驱动）不是白块成因。** 封顶时它只给 c 加 `(0.035, 0.06, 0.10)`（L1266），并把 c 乘 `(0.87,0.93,1.0)`（L1265）——加不到白阈值。用户观察「stored=0 也白 / stored 高也白不了」与此吻合：白不白在**片法线朝向主光 + 环境反射采样**（片间静态差异），不在 stored。
4. **p=0.9 展开态「外圈 band3 怎么打都不白」= 这些片背向主光**（L1012 `c *= 0.26+0.74·pow(key,1.25)`，key=0 时砍到 0.26×）且环境反射落到暗带；命中只加一道 σ≈0.016·u_hitR 的细环（L1297），不是整片白。
5. **p=0.35–0.8 闭合态内外都白**：基准面 shellInner 的五边形勾边项带 `(1+1.15·closed)=2.15×`（L1424），加上白色 spec 项 `vec3(1.0)·spec`（L1446）——与上午消融（关 shellInner 白块 1.89%→0.09%）完全吻合。

### 1.2 Composer pass 清单（scene.js L193-199，顺序即执行顺序）

| # | Pass | 参数（默认） | 控制入口 |
|---|---|---|---|

### 1.3 L5FxShader 片元做了什么（scene.js L52-138）

按执行序：
1. 采样 `tDiffuse`（bloom 后）+ `tGlow`（半分辨率辐射链，`L5Radiance`，scene.js L297-301）。
2. 径向色差（L95-99）、辐射光晕+光轴加色（L102）、暗角（L106-107）、高亮去饱和对冲（L110-112）。
3. **Reinhard 软膝（L126-131）**：`knee=0.85`，`over=mx-0.85`，新峰值 = `0.85 + over/(1+over/0.55)`，三通道同比缩放。渐近上限 = 0.85+0.55 = **1.40 线性**。
4. 细颗粒（L134-135，±0.016）。

> 关键：软膝在 bloom **之后**、ACES **之前**。bloom 阈值 1.0 仍按原始 HDR 亮度触发；但任何过 1.40 线性的东西进 ACES 前都被压回 ≤1.40。

### 1.4 辐射链（fx 增强，非 pass）
`L5Radiance`（radiance.js）每帧先渲染一层 GLOW_LAYER 掩膜→半分辨率高斯→作为 `tGlow` 喂给 L5FxShader（scene.js L296-302）。闸门：`spill = smoothstep(e0, 1.5, 3.5)`（scene.js L240-241，SPILL_FLOOR=1.5，photometry.js L25）；`fx=0` 时整链关闭。

## 2. 过曝阈值估算（ACES 查表过程）

ACES（Narkowicz）：`f(x) = (2.51x²+0.03x)/(2.43x²+0.59x+0.14)`，再 sRGB OETF。

### 2.1 全链路表（先软膝后 ACES，与管线一致）

| 输入线性 L | 软膝后 | ACES 输出 | sRGB (0–255) |
|---:|---:|---:|---:|
| 0.10 | 0.100 | 0.126 | 99 |
| 0.20 | 0.200 | 0.300 | **149** ← 用户「白块」阈值 |
| 0.30 | 0.300 | 0.439 | 177 |
| 0.50 | 0.500 | 0.616 | 206 |
| 0.70 | 0.700 | 0.717 | 220 |
| 0.85 | 0.850 | 0.767 | 227 |
| 1.00 | 0.968 | 0.797 | 231 |
| 1.50 | 1.148 | 0.832 | **235** |
| 2.00 | 1.222 | 0.843 | 237 |
| 5.00 | 1.336 | 0.858 | 238 |

**结论：线性 1.0/1.5/2.0 经 ACES+软膝分别落到 231/235/237，全不是 255。** 纯 255 需要软膝前 L≈10（软膝渐近 1.40 后数学上到不了），即本项目里**不存在 255 纯白像素**——中心核心也被 CORE_KNEE=0.95 / CORE_HEAD=0.75 软压到渐近 1.70 线性（l5Core.js L585-586, L1589-1593），再经 L5Fx 软膝 → ≈238/255。

### 2.2 反解：用户「白块」口径对应多少线性

| sRGB 目标 | 对应线性 L（软膝前） |
|---:|---:|
| 140/255 (0.549) | **0.178** |
| 150/255 (0.588) | **0.203** |
| 204/255 (0.80) | 0.481 |
| 230/255 (0.90) | 0.940 |

→ **只要某片加色后线性亮度 ≥0.20 且 R/B 都 ≥0.18，就被判为「白块」。** 这个阈值非常低——晶体本体钳到 0.85、基准面线条 0.3–0.7 都会触发。所谓「过曝」其实是 ACES 低段陡升，不是 bloom 烧穿。

### 2.3 bloom 阈值 1.0 谁会触发
- 晶体本体：钳到 0.85（L1128-1131）→ **不触发**。
- 基准面：钳到 1.25（L1497-1498）→ 线心偶尔超 1.0，轻微 bloom。
- 脉冲线 `pulseCol·1.05·pulse`：p=0.9 时 `pulseCol=(1.14,0.58,0.36)`（见 §5.2），红通道超 1.0 → 细红线 bloom。
- 命中线：`u_hitGain=2.10`（L175, L1996）使峰值 ≈1.5 → 触发 bloom，但线极细。

## 4. 撞击队列时序（p=0.9 稳态）

### 4.1 排程（l5Core.js L3208-3349）
- 仅 `active`（p≥0.80）时运行；未展开清空队列（L3309-3311）。
- 每面外圈 n 片，队列长 L=n+1~n+2（L3221-3222），洗牌错序，时间分层铺开在窗口 `span = max(1.10s, 到下次转动)`（L3220, L3322）。
- 到点 → `_assignHitParticle` 挑最近巡航粒子螺旋俯冲（飞行 0.15–0.6s，注释 L3268）→ 粒子到达（dist<0.16）时**同帧** `stored+1`（L2571）、`u_hitT=0` 起走片级脉冲（L2592）、`impactW=1`（L2580）。

### 4.2 单片脉冲寿命
- `u_hitT` 以 `dt/HIT_PULSE_DUR`（HIT_PULSE_DUR=0.46s，L166, L2716-2717）从 0→1，走完置 -1。
- 可见窗：`smoothstep(0,0.12,u_hitT)` 升起、`(1-smoothstep(0.90,1,u_hitT))` 落下（L1298/1302）。
- → 命中线在 **0.055s 全亮、0.414s 后消失**。每片被同窗口限一次（`HIT_FRAG_GAP=0.9s`，L171；全局限流 `HIT_GLOBAL_GAP=0.14s`，L169，但队列通道不走限流，L3246 注释）。

### 4.3 p=0.9 稳态「某时刻哪些面在发白脉冲」
- 每面每 1.1s 窗口内 n 片外圈各中一次，时间均匀散布 → 任一时刻全 12 面约有 `12·n·(0.414/1.1)` 片处于命中线可见窗。若 n≈8（外圈片数），≈ 36 片/帧同时有细环——但每片只有 1–2px 宽的环，不是整片白。
- 叠加：循环轮廓脉冲在 p>0.80 时 `u_pulse_gate=0`（L3068 第二项）→ **p=0.9 时面心扩散脉冲环是关的**。此时唯一周期性脉冲就是命中细环 + 一次性爆发（跨阈值后 0.72s）。

## 5. 基准面 shellInner 时序与淡出门控

### 5.1 细线环擦除排程（`_animateBasePulse`，L3153-3176）

- 环增益 `ringEnv = running ? 1-smoothstep(prog,0.72,1.0) : 0`（L3165-3166）→ 细线环只在前 **0.30s** 亮，走完归零，不留常亮环。
- 片元里 `bBand = exp(-((rb-bFront)/0.011)²)·u_revB.z·(1-smoothstep(0.80,1,bU))`（L1479-1480），颜色 `mix((0.62,0.86,1.0), emissive, 0.25)·BASE_RING_GAIN(0.52)`（L1481, L255）。

### 5.2 展开淡出（L3546-3565）
```
innerFade = 1 - 0.60·smoothstep(_deploy, 0, 0.55)        // L3546-3547
u_shell_fade = innerFade                                  // L3549（乘 c 和 alpha）
u_base_boost = min(8, 1+(1/atten -1)·smoothstep(p,0.76,0.94)·1.25)  // L3564-3565
```
- 闭合（deploy=0）：innerFade=1.0，shellInner 全亮。
- 展开稳态（deploy=1, p=0.9）：innerFade=0.40，擦除后 bVis=BASE_HIDE_LEVEL=0.50 → `atten=0.40·0.50=0.20`，`_need=5.0`，boost=1+4·0.5·1.25=**3.5** → shellInner 净亮度 = `0.20·3.5 = 0.70` 的闭合态。
- `u_lift = BASE_LIFT(0.10)·liftEnv`（L3578, L301）。

## 7. 稳态静态白 vs 瞬时脉冲白 判定清单

### 7.1 稳态静态白（给定 p 后不随时间消失，只随视角/片法线变）

| shellInner 五边形勾边（闭合态 2.15×） | L1422-1424 | p<0.8 闭合态常驻脉动 |

### 7.3 对用户两条观察的直接解释
- **「p>0.8 展开态，band3 外圈片怎么打都不白（stored 高也白不了）」**：band3 片法线多背向主光 `Lw=(0.42,0.86,0.34)`，L1012 砍到 0.26×；命中只加细环（7.2 表第 1 行），stored 只加 ≤0.10（§6.2）。三者都不把整片推到 0.20 线性白阈值以上。
- **「有些内部片 stored=0 也是白的」**：内部片法线朝主光/环境亮带，本体满幅 ≤0.85 线性（§6.3 deploy=1 行），加色 ≈0.64 → sRGB≈0.84。与 stored 无关，是静态法线差异。
- **「p 0.35–0.8 闭合态内外都白」**：shellInner 在闭合态全亮且勾边 2.15×（§5.3），晶体片被 reveal=0.42 压薄后透出下面的 shellInner。与上午消融（关 shellInner 1.89%→0.09%）一致。

## 8. 后处理过曝判定（哪些增益组合会越白阈值）

- **不会烧穿**：晶体本体（钳 0.85）、shellInner 本体（钳 1.25）、u_cool（≤+0.10）——这些加起来稳态落在 sRGB 0.6–0.88，是「亮」不是「过曝」。
- **细线性 bloom**：命中线（×2.10 → ≈1.5）、爆发（pulseCol 1.14·1.05）、基准面 spec（白色 0.34）——仅细线、瞬态。
- **软膝兜底**：任何 ≥1.40 线性的输入都被压回 1.40 → sRGB 天花板 ≈0.93（238/255）。本项目不存在把中高亮度「拉成纯白」的后处理；观感上的「白块」= ACES 低段增益 + 壳体本征亮面，与 bloom/曝光无关。
- **可调杠杆**：`?tk_bloomT` 调高（>1.5）可关掉细线 bloom；`?tk_expo<1` 整体压暗；`?tk_body=0.5`（L3396 `u_body_gain`）直接砍晶体本体 0.72→0.36 档。
