# F 阶段：碎块发白根因修复报告

> 目标：把 p=0.35–0.8 闭合态白（基准面 shellInner 透射）与 p>0.8 展开态白（晶体碎块本体亮度）压下去，同时增强 band3 外片被击中后的冷蓝可见反馈。只改 `src/gfx/l5Core.js`，已验收特性不可破坏，git 不提交。
> 测量口径：亮度>150 且 R>140 且 B>140；采样 x[0.18,0.60]w、y[0.15,0.80]h、步长 3。
> 测量方法：headless Chrome 153 + swiftshader，稳态 sim≥6s 后 `setShowcase(false)` 停自旋（pin 到 AXON_TILT_Y 固定角），不暂停时钟（暂停会导致 rAF 不渲染、截图 stale）。front 用默认正交相机（z=50），rot45 绕 Y 轴同距离转 45°。

### 后处理对照（?fx=0，补 C 缺口）

| 测点 | fx=1(开) | fx=0(关) | bloom 贡献 |
|---|---|---|---|
| p=0.5 front | 0.575% | 0.065% | 0.51% |
| p=0.5 rot45 | 0.575% | 0.433% | 0.14% |
| p=0.9 front | 0.988% | 0.807% | 0.18% |

**结论**：p=0.9 rot45 剩余 3.18% 中，真实渲染仅 1.17%，其余 2.0% 是 bloom 光晕（亮晶体面周围的 HDR 泛光）。p=0.5 front 剩余 0.575% 中 bloom 贡献 0.51%（shell 勾边边缘光晕）。这排除了"HDR 后处理把暗部提亮成片白"——白的根源在渲染本体，后处理只是放大边缘光晕。

## 6. 仍存在的缺口 / 未达"接近背景参照"的项

1. **p=0.9 rot45 仍 3.18%**（基线 4.96%，降 36%）。其中真实渲染 1.17%、bloom 光晕 2.0%。真实渲染部分是晶体掠射棱面 envT 透射（半透明蓝水晶的固有亮面），继续压会破坏"半透明蓝色水晶"视觉。bloom 光晕属后处理，未改（改 bloom 强度会影响全局观感，超出"只改 l5Core.js shader"范围）。
2. **p=0.5 front 仍 0.575%**（基线 0.826%）。剩余白是 shellInner 五边形勾边（验收特性"20-80 基准面轮廓透出"），色 (152,185,179) R=144 刚过阈值。再压会破坏轮廓透出验收。
3. **p=0.5 rot45 0.575%**：闭合态对称，rot45 与 front 同值，同上述勾边。
4. 未单独测 p=0.5 脉冲环特写（脉冲环在 FSM 切换时短暂出现，稳态截图不含；代码层仅降白注入未删结构）。
